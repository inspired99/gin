# fixgaz

Дневник режима на двоих: кальян, клуб, тренировки и коворкинг. Статический сайт без сборки и без авторизации, синхронизация через Firebase Realtime Database.

## Запуск у себя

```bash
python3 -m http.server 8765
```

Открыть `http://127.0.0.1:8765`. Без адреса базы в `config.js` дневник живет только в этом браузере.

Пример с выдуманным журналом: `http://127.0.0.1:8765/?demo`. Нужный экран можно открыть ссылкой: `?demo&me=0&open=stats`, где `open` это `stats`, `rules`, `log`, `plan`, `menu` или `goal` (лист достижения).

## Тесты

```bash
node --test tests/*.test.js
```

Зависимостей нет, нужен только Node 20 или новее.

## Подключить синхронизацию

1. В [консоли Firebase](https://console.firebase.google.com) создать проект. Аналитика не нужна.
2. Build, Realtime Database, Create Database. Регион любой, режим locked.
3. На вкладке Rules вставить правила ниже и нажать Publish.
4. Скопировать адрес базы со вкладки Data. Он выглядит как `https://имя-default-rtdb.europe-west1.firebasedatabase.app`.
5. Вписать адрес в `config.js`:

```js
export const DB_URL = 'https://имя-default-rtdb.europe-west1.firebasedatabase.app';
```

Правила базы:

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "rooms": {
      "$room": {
        ".read": "$room.length >= 20",
        ".write": "$room.length >= 20"
      }
    }
  }
}
```

Корень закрыт, поэтому список дневников получить нельзя. Доступ дает только длинный случайный ключ комнаты из ссылки `#room=...`. Кто знает ссылку, тот может читать и писать, поэтому ссылку отправляем только друг другу. Адрес базы в `config.js` публичный, ключ комнаты в репозиторий не попадает.

После подключения: один создает дневник и отправляет ссылку второму. Второй открывает ее и выбирает своего персонажа.

Чтобы дневник был один на двоих без всяких ссылок, впишите его ключ в `config.js`:

```js
export const ROOM = 'ключ из ссылки после #room=';
```

Тогда любой телефон и любой значок на домашнем экране открывают этот дневник. Если на устройстве раньше был другой дневник, приложение предложит перенести из него отметки в общий (повторы пропускаются). Ключ при этом виден всем, кто знает адрес сайта.

## Публикация на GitHub Pages

В настройках Pages источник: GitHub Actions. Workflow `.github/workflows/pages.yml` на каждый пуш в `main` прогоняет тесты и выкладывает только файлы сайта. Сборки нет, но при выкладке пишется `version.json` с хешем коммита: по нему открытое приложение узнает о новой версии и обновляется само (при запуске и при возвращении в него). В приложении с домашнего экрана страницу обновляет свайп вниз, в меню есть кнопка «обновить приложение».

## Как устроено

| Файл | Что в нем |
|---|---|
| `js/rules.js` | правила: лимиты, нарушения, штрафы, бриллианты недели, уровень, достижения. Чистые функции, покрыты тестами |
| `js/model.js` | модель для разметки: все, что нужно экрану, из журнала и состояния |
| `js/store.js` | состояние: снимок с сервера плюс очередь неотправленных записей |
| `js/sync.js` | адаптеры хранилища: локальный, Firebase, память для примера |
| `js/update.js` | обновление приложения: перечитать файлы мимо кеша, проверка новой версии |
| `js/ui.js` | разметка экранов и листов |
| `js/main.js` | запуск, состояние экрана, обработка действий |
| `js/sprites.js` | значки и наклейки пиксельными сетками, герои и джинн картинками |
| `js/copy.js` | тексты и форматирование дат |
| `css/tokens.css` | цвета, шрифты, шаг сетки |

Журнал только пополняется: удаление это пометка `del`. Лимиты, бриллианты, уровень и достижения вычисляются из журнала при каждой отрисовке, производное состояние не хранится.

## Картинки

Герои и джинн нарисованы владельцем. Исходный лист лежит в `assets/src/sheet.png`, промпты в `assets/PROMPTS.md`. Нарезка на позы:

```bash
node tools/sprites.mjs assets/src/sheet.png
```

Нужны `ffmpeg` и `cwebp`. Скрипт убирает пурпурный фон, выравнивает позы по подошвам и пишет WebP в `assets/sprites/`.

Декор (факел, фонарь, тыква, листья, свеча) режется тем же скриптом из `assets/src/props.png` в `assets/props/`:

```bash
node tools/sprites.mjs props
```

Джинн по уровням (шесть стадий, сетка 3 на 2) режется из `assets/src/genie-levels.webp` в `assets/sprites/genie-lvl-0.webp` ... `genie-lvl-10.webp`:

```bash
node tools/sprites.mjs genies
```

Комнатка и деревянная стена тоже нарисованы владельцем (`assets/src/scene.webp`, `assets/src/wall.webp`). Комнатка уменьшается до 1280 px по ширине, стена затемняется вдвое, чтобы светлый текст на ней проходил по контрасту:

```bash
ffmpeg -y -i assets/src/scene.webp -vf "scale=1280:-2:flags=lanczos" /tmp/scene.png
cwebp -q 84 -m 6 /tmp/scene.png -o assets/bg/room.webp
ffmpeg -y -i assets/src/wall.webp -vf "colorchannelmixer=rr=0.50:gg=0.50:bb=0.50" /tmp/wall-dark.png
cwebp -q 82 -m 6 /tmp/wall-dark.png -o assets/bg/wall.webp
```
